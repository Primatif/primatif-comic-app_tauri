# Comic Panel Creator

A desktop application for comic artists and creators. Digital workspace for visual layout planning, content creation, and production workflow management with AI-assisted tools.

## Technology Stack

- **Frontend**: SolidJS, TypeScript, Tailwind CSS
- **Backend**: Tauri, Rust, SQLite
- **Features**: AI script generation, vector drawing, professional export

## Development Setup

```bash
# Clone and install
git clone https://github.com/Primatif/primatif-comic-app_tauri.git
cd primatif-comic-app_tauri
pnpm install

# Start development
pnpm tauri dev

# Build for production
pnpm tauri build
```

## Requirements

- Node.js (v18+)
- Rust (latest stable)
- pnpm or npm
