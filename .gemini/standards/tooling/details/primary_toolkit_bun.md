# Primary Toolkit: Bun

Bun is designated as the official toolkit for this project. It is used for:

-   **Package Management**: Handling all project dependencies.
-   **Script Execution**: Running all defined scripts in `package.json`.
-   **Testing**: Executing project tests.

Using Bun ensures a simple, fast, and consistent development environment across all developer machines and CI/CD pipelines. Its all-in-one nature streamlines workflows and reduces the overhead associated with managing multiple tools.
