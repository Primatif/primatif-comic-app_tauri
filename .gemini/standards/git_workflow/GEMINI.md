# Git Workflow Standards

This document outlines conventions for a clear Git history, including commit message style and changelog management.

## 1. Commit Message Style Guide

This project uses **Conventional Commits** for a clear Git history, aligning with `semantic-release`.
- **Summary**: Defines the format, types, scope, and description for commit messages.
- **For detailed explanation and examples**: Refer to `/.gemini/standards/git_workflow/details/commit_message_style_guide.md`.

## 2. Changelog Management Standard

This document outlines conventions for `docs/update-logs/changelog.txt`, ensuring a clear, consistent history.
- **Summary**: Specifies file location, ordering, and entry format for changelog entries.
- **For detailed explanation and examples**: Refer to `/.gemini/standards/git_workflow/details/changelog_management_standard.md`.
